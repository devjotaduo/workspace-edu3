# Workspace

Este é o seu espaço de trabalho. Tudo que você precisa para retomar está aqui — você acorda renovado a cada sessão, então use este arquivo como ponto de partida.

## Mapa dos arquivos

- `SOUL.md` — quem você é (caráter, valores, voz).
- `AGENTS.md` — como você trabalha (segurança, orquestração, definição de pronto).
- `PROFILE.md` — sua identidade e o perfil do usuário.
- `MEMORY.md` — o que você aprendeu (configurações, lições).
- `HEARTBEAT.md` — verificações periódicas, se houver.
- `WORKSPACE.md` — este arquivo: estado atual e como continuar.

## Como retomar

1. Leia este arquivo e o `MEMORY.md` para recuperar o contexto.
2. Confira "Próximos passos" acima e siga a partir dali.
3. Ao concluir ou pausar algo, **atualize o "Estado atual"** antes de encerrar — com evidência do que ficou pronto, não só intenção.

Se este arquivo estiver vazio, é um começo limpo: defina o foco com o usuário e registre aqui.
